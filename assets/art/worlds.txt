# PAPERMARCH worlds: how each world looks (docs/ART_DIRECTION.md sections 7, 8, 12). Stage 1: world 1 only.
# world <n> <name>
# road <file> <width> <tile>      texture; the width in units it spans across the road and both curbs; one repeat's length
#                                 u = (x + width/2) / width, v = z / tile; the image's first row is v = 0
# land <file> <tile>              u = x / tile, v = z / tile
# haze <0xRRGGBB> <start> <end>   distance fog, units ahead of the camera's foot (smoothstep)
# sky <top> <horizon>
# backdrop <file> <height>        bottom edge on the horizon, as wide as the screen; height = share of the screen's width
# light <0xRRGGBB> <strength>     grade: colour *= mix(1, light, strength)
# grade <contrast> <saturation>
# bloom <threshold> <strength>
# vignette <strength>
# shadow <dx> <dz> <alpha>        cast shadows: ground offset per unit of height; opacity (colour 0x1B2A55)
# prop <kind> <weight> <scaleMin> <scaleMax> <xMin> <xMax> <spacing>
#                                 per side: one candidate every <spacing> units of road (z jittered by +-spacing/2),
#                                 kept with probability <weight>; |x| uniform in xMin..xMax; scale uniform
# edge <kind> <spacing> <x>       both sides at |x|, every <spacing> units
# ambient <kind> <perSecond>
